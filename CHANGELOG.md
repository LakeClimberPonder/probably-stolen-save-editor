# Changelog

## [1.0.0] — November 2026

### Added
- Credits editor (add/remove/set any amount)
- Rent and debt control (freeze rent, clear loans)
- Item editor (add any weapon, contraband, consumable)
- Reputation editor (max faction reputation, unlock perks)
- Inspection bypass (clear crime records)
- Auto-backup before saving
- Native C++ build, 4.2 MB, no runtime dependencies
